# 业务规则

1. 所有必需字段先通过契约检查，再按 ticket_id 去重。ID 冲突不自动选择最新版。
2. 按 created_date 等于用户指定日期筛选。本日报表示该日创建工单当前的状态，不表示当日完成数量。
3. total 为范围内唯一工单数。completed 和 open 按 status 分类，二者之和应等于 total。
4. completed_minutes 为已完成工单 minutes 之和。平均耗时为该和除以 completed，保留两位小数。open 工单不进入平均耗时分母。
5. 核对原始行数 = 重复行数 + 跨日期唯一行数 + 范围内唯一行数，并独立按范围内记录重算输出字段。

这是固定教学口径。用于真实业务之前，须确认实际字段、时间粒度、状态定义、去重策略和验收标准。
