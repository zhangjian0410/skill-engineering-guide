# 数据契约

输入为 UTF-8 JSON 数组，每项为一个工单对象。

| 字段 | 类型与约束 |
|---|---|
| ticket_id | 非空字符串，区分大小写，首尾空白去除后作唯一键 |
| created_date | 严格 YYYY-MM-DD 格式，真实日历日期 |
| status | completed 或 open |
| minutes | 0 到 2147483647 的整数，布尔值不算整数；completed 必须大于 0，open 必须为 0。上限采用教学接口的 32 位整数范围，保证两位小数平均值可表示，不是业务耗时约束 |

额外字段忽略。数组可为空。完全一致的必需字段构成重复记录，计数后剔除。相同 ID 的必需字段冲突必须停止。输入所有记录均需有效，即使不在统计日期内。

输出 report.json：date、total、completed、open、completed_minutes、average_completed_minutes。平均耗时保留两位小数，四舍五入；没有完成单时为 null，不能填 0 冒充测量值。report.txt 提供同口径的文字版。evidence.json 留输入 SHA-256、规则与脚本 SHA-256、运行 ID、UTC 开始时间、处理计数和校验结果。

数据或写出失败不发布输出目录。文件先写入同目录下的临时位置，完整写出后才发布到新目录；已有目录一律拒绝覆盖。同一输出位置的协作并发由临时锁拒绝。教学练习只操作指定本地文件，无网络、消息发送或业务写回。
