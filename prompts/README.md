# Skill Engineering 通用自评提示词

版本与状态见 [metadata.json](metadata.json)。当前为试用版，尚未完成跨 Skill、跨平台的模型执行验收。

[skill-self-review.txt](skill-self-review.txt) 是唯一维护源。网页预览和下载文件由构建脚本生成，修改时只编辑此文件。

## 使用

1. 在能读取目标 Skill 的 AI 工具中打开新对话。
2. 把提示词中的 `【Skill 名称】` 替换为自己的 Skill 名称，或从[公开自评页面](https://skill-engineering-guide.pages.dev/self-review.html)填写名称后复制。
3. 默认执行只读基础筛查，报告完成后询问是否继续深度筛查。深度可以直接发起，也会重新核对已有基础发现。

找不到 Skill 或无法读取正文时，工具会请求路径或附件。注册信息和技能目录按所用平台定位，模板不硬编码平台路径。

模板按数据处理、写作与分析、流程与工具调用自动适配检查；支持混合类型。简单任务不强制脚本或测试目录。基础、深度均为只读，执行验证和修复需要另行明确授权。

## 验证与维护

[evaluation-cases.json](evaluation-cases.json) 包含合成材料和预期评审行为，用于后续在实际工具中做回归。每个案例的 `observed`、`verdict` 保留未运行状态；文件存在不代表模型执行验收通过。

网页构建、复制、下载和源码一致性检查仅验证网站功能，不证明模型会遵从提示词。实际运行后记录平台、模型、提示词版本、观察结果和判定，再决定是否发布稳定版。

本版本保留本会话确定的三项优先检查、基础结束邀请、深度独立发起、证据分级和读取范围约束。实际薪资文件、员工数据和业务筛查报告不纳入示例材料。
